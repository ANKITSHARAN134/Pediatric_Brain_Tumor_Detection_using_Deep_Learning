🧠 Pediatric Brain Tumor Detection using Deep Learning
This project aims to detect and classify pediatric brain tumors using deep learning techniques applied to MRI images. 
With a focus on non-invasive medical imaging and neural networks, our work contributes to the advancement of automated, accurate diagnosis in pediatric neuro-oncology.

🛠️ Technologies Used

-> Python

-> Jupyter Notebook

-> TensorFlow / Keras

-> OpenCV

->NumPy / Pandas

->Matplotlib / Seaborn

🔬 Key Contributions & Findings:

-> Developed CNN-based models for tumor classification and segmentation

-> Leveraged transfer learning and ensemble methods for enhanced model performance

-> Focused on pediatric-specific challenges, where data is limited and tumor types are varied

-> Evaluated using metrics like accuracy, F1 score, Dice coefficient, and ROC AUC

📊 Performance Metrics:

| Task                 | Metric                  | Result         |
| -------------------- | ----------------------- | -------------- |
| Tumor Detection      | Classification Accuracy |    > 90%       |
| Tumor Segmentation   | Dice Coefficient        |    Up to 0.94  |
| Tumor Classification | F1 Score                |    ≈ 0.80+     |
| ROC AUC              | Tumor Type Detection    |    > 0.99      |
